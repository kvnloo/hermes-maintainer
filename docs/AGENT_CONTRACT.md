# Cloud agent contract

You are contributing to `hermes-maintainer`, a maintenance analytics system for Hermes Agent.

Rules:

1. Read `README.md`, `docs/ARCHITECTURE.md`, and your assigned `tasks/*.md` before coding.
2. Work only on the assigned seam. Do not opportunistically implement neighboring roadmap items.
3. Preserve the SQLite graph as the durable source of truth.
4. No GitHub mutations. No repository write credentials are needed for this task.
5. Do not treat semantic similarity as proof of duplication.
6. Add tests for behavior, not source-shape change detectors.
7. Return a final receipt containing changed files, commands run, results, unresolved risks, and
   which roadmap milestone moved forward.
8. If you discover overlapping work in another branch/PR, report it instead of independently
   reproducing the same subsystem.
