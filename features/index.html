THE METHOD

Not another backlog

Specs complement canonical issue and promotion queues. They don't replace them.

01 / INTENT

Why build it?

State the user problem, constraints and the smallest experience that solves it.

02 / DESIGN

How should it behave?

Document interactions, architecture, decisions, alternatives and linked source.

03 / VERIFICATION

What proves it works?

Keep acceptance tests, exact evidence and rollout gates visible beside the proposal.

Adding another feature? Follow the PRD authoring contract. Each feature owns its own folder; the library remains a navigation surface.
